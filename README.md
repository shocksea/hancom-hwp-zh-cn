# Hancom Office 2024 简体中文汉化

把 Hancom Office 2024（HWP、HCell、HShow、HWord 等）的韩文界面汉化为简体中文。

- 适用版本：HWP 13.0.0.4131（必须完全一致，版本不符时会拒绝安装）
- 下载：[Releases](../../releases)

## 安装

1. 下载 zip，解压到本机硬盘的短路径下，如 `C:\hwp-l10n`。
2. 双击 `install.cmd`。如弹出安全警告，选择「运行」；询问管理员权限时选择「是」。
3. 安装完成后打开 HWP 即可。

## 卸载

双击 `uninstall.cmd`。安装时会在 `%ProgramData%\hwp-l10n\` 保留一份卸载工具，删除安装包后仍可从那里卸载。

注意事项和未汉化的内容见压缩包内的 `README.txt`。
